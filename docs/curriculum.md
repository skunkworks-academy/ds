# Course Curriculum

| Module | Outcomes | Assessment evidence |
|---|---|---|
| Cloud architecture | Design identity, network, compute, storage, governance, resilience and cost controls | Reference architecture + ADRs |
| Security operations | Build detection, triage, incident and metrics logic | Detection pack + incident report |
| Zero Trust | Apply identity, endpoint, network, application and data controls | Zero Trust architecture |
| Endpoint engineering | Govern devices, compliance, hardening and exceptions | Endpoint baseline |
| PowerShell automation | Build safe, logged, testable administration automation | Script + tests + runbook |
| GitHub & DevSecOps | Use branching, PR review, Actions and secret hygiene | CI workflow + evidence |
| Infrastructure as Code | Build reusable and governed non-production infrastructure | Bicep/Terraform baseline |
| Risk & governance | Translate technical exposure into risks, controls and decisions | Risk register + control matrix |
| Resilience | Design backup, recovery, dependencies and operational continuity | Recovery architecture + tabletop |
| Strategic leadership | Build business cases, roadmaps and stakeholder narratives | Executive brief + presentation |

## Assessment model

| Dimension | Weight |
|---|---:|
| Technical and architectural quality | 25% |
| Security and risk reasoning | 20% |
| Automation / reproducibility | 15% |
| Testing and evidence quality | 15% |
| Business impact and communication | 15% |
| Leadership, mentoring and reflection | 10% |

**Pass:** 75%  
**Distinction:** 90%

A submission containing unauthorised sensitive data cannot pass until corrected.
