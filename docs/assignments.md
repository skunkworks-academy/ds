# Assignments

## Assignment 1 — Senior capability baseline
Produce a one-page matrix: current strength, evidence, target level, gap, 90-day action.

## Assignment 2 — Architecture decision record set
Write three ADRs covering identity, endpoint and logging choices. Include alternatives and trade-offs.

## Assignment 3 — Security operations scorecard
Define detection coverage, mean time to acknowledge, mean time to contain, false-positive rate, asset coverage and lessons-learned metrics.

## Assignment 4 — Automation quality review
Take one PowerShell automation and document inputs, permissions, tests, logging, failure modes and rollback.

## Assignment 5 — Risk-to-business translation
Convert five technical risks into executive language with likelihood, impact, control owner, cost/effort and decision required.

## Assignment 6 — Leadership retrospective
Document one project or simulated capstone using context, decision, outcome, stakeholder communication, what changed and what you would do differently.

## Scoring

Each assignment is reviewed against the curriculum rubric. Mentor feedback must be answered in the next revision rather than stored as passive comments.
