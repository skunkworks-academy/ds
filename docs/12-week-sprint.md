# 12-Week Applied Sprint

<div className="idr-badges"><span className="idr-badge">3–4 hours weekly</span><span className="idr-badge">On-the-job aligned</span><span className="idr-badge">Evidence required</span><span className="idr-badge">Fortnightly review</span></div>

| Week | Focus | Learning module | Practical output |
|---:|---|---|---|
| 1 | Baseline & architecture | Senior-role gap analysis, architecture principles, Git workflow | Capability matrix and architecture decision record template |
| 2 | Identity & Zero Trust | Entra, MFA, Conditional Access, identity lifecycle | Identity and access reference design using synthetic users |
| 3 | Endpoint security | Intune, Defender, compliance, attack-surface reduction | Secure endpoint baseline and exception model |
| 4 | SOC & SIEM | Sentinel concepts, detections, incident lifecycle, ATT&CK | Synthetic detection rules, triage worksheet and SOC metrics |
| 5 | Incident response | Severity, evidence, containment, communications | Tabletop runbook for a simulated endpoint compromise |
| 6 | PowerShell automation | Idempotence, logging, validation, error handling | Tested administrative automation script using safe lab data |
| 7 | GitHub & secure delivery | Git, pull requests, Actions, secrets hygiene | CI workflow for lint/test/validation of the automation project |
| 8 | Infrastructure as Code | Bicep/Terraform concepts, state, modules, guardrails | Reproducible non-production baseline architecture |
| 9 | Cloud governance | Landing zones, policy, tagging, cost, resilience | Azure-first governance blueprint with AWS comparison notes |
| 10 | Risk & compliance | Risk register, control mapping, exceptions, evidence | Security risk register and control-to-evidence matrix |
| 11 | Strategic leadership | Business case, roadmap, budget assumptions, stakeholders | Executive security-modernisation brief |
| 12 | Capstone & career conversion | Portfolio review, presentation, interview stories | Ten-minute architecture presentation and 90-day next-step plan |

## Completion rule

A week is complete only when Desh can **explain the decision, demonstrate the evidence, document limitations, protect confidential information and respond to review feedback**.
