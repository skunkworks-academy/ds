# Credential and Skill Milestones

Credentials are supporting milestones, not the purpose of the IDR. A credential target counts only when it reinforces the architecture, security, automation or leadership evidence Desh is building.

:::info Currentness rule
Certification names, skills measured and retirement dates change. Check the official vendor page before booking an exam. The [References](/idr/references/) page is the source register used by this IDR.
:::

## Important AZ-500 change

Microsoft's current credential-retirement information states that **Azure Security Engineer Associate / AZ-500 retires on 31 August 2026**. Because this IDR runs beyond that date:

- do not plan the 12-month roadmap around AZ-500 availability;
- use the current AZ-500 objectives only as a short-term Azure security skills reference;
- at the Day-30 mentor review, replace it with the most relevant current Microsoft security credential or Applied Skills option if a successor is available and valuable.

Official retirement register: https://learn.microsoft.com/credentials/support/credential-retirement

## Credential sequencing

### Phase 1 — Weeks 1–4

Prioritise GitHub workflow evidence plus SC-300/SC-200 study alignment. These map directly to the Zero Trust and SOC artefacts.

### Phase 2 — Weeks 5–8

Add MD-102 and AZ-104-aligned evidence while building automation and IaC. The goal is not four simultaneous exam preparations; use the objectives to structure labs and identify gaps.

### Phase 3 — Weeks 9–12

Add AWS/Cisco cross-domain learning and governance/leadership evidence. Confirm which credential, if any, is worth formal exam booking after the sprint.

## Acceptance gate

A milestone counts only when Desh can show at least one of:

- a current certificate or official badge;
- a completed official learning record;
- a working lab tied to the credential objectives;
- a reviewed architecture artefact;
- a tested automation/IaC artefact;
- a mentor-accepted portfolio item.

## Credential score

Use this evidence scale:

| Score | Meaning |
|---:|---|
| 0 | Not started / not relevant |
| 1 | Objective reviewed; no evidence yet |
| 2 | Learning in progress with notes/labs |
| 3 | Working evidence demonstrates part of the capability |
| 4 | Mentor-reviewed evidence or current credential |
| 5 | Capability is applied across multiple projects and can be defended in an interview |

The annual KPI is **4 core + 4 supporting/applied milestones** at score 4 or higher, not a fixed number of exams.
