# Portfolio Projects

## Project 1 — SOC Detection Pack
Synthetic detections, ATT&CK mapping, triage flow, incident metrics and false-positive handling.

## Project 2 — Zero Trust Reference Architecture
Identity, endpoint, network, apps, data, logging, exceptions and privileged-access model.

## Project 3 — Secure Endpoint Engineering Baseline
Intune/Defender architecture, update strategy, compliance, exception process and measurable operating KPIs.

## Project 4 — Infrastructure-as-Code Baseline
Bicep or Terraform modules for a safe non-production environment, with validation, teardown and governance notes.

## Project 5 — Automation & Compliance Toolkit
PowerShell utilities for safe administrative checks or configuration reporting, with tests, logs and documentation.

## Project 6 — Strategic Security Modernisation Brief
An executive-ready proposal that connects current-state risks, target architecture, roadmap, budget assumptions, KPIs, governance and business outcomes.

## Portfolio quality gate

Each project must contain a README, architecture or workflow diagram, authorised scope, tests or validation, security/privacy notes, evidence, limitations, lessons learned and mentor review.
