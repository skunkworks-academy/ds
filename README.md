# Deshan Singh — Individual Development Roadmap

Interactive Docusaurus learning and career-development workspace for Deshan (Desh) Singh.

## Production

- Canonical domain: https://ds.skunkworksacademy.com/
- Framework: Docusaurus 3
- Public shell: Skunkworks Academy canonical global header/footer
- Mentor/facilitator: Raydo Matthee
- Full PDF: https://ds.skunkworksacademy.com/downloads/Deshan_Singh_Individual_Development_Roadmap.pdf

The PDF is generated automatically during the production build from the current roadmap release and is validated before GitHub Pages deployment.

## Local development

```bash
npm install
npm run start
```

## Quality gate

```bash
npm run check
```

The quality gate validates the Academy shell, privacy boundary, 12-week structure and downloadable PDF integration, then generates the PDF and runs the Docusaurus production build.

## Privacy

This repository is public. The online IDR is a sanitised development plan. Do not commit personal contact information, banking information, confidential employer data, credentials, customer data, private assessment responses, security secrets or production logs. Use synthetic or expressly authorised evidence only.
